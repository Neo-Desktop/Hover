# Pixel "MS Sans Serif"

The Windows 95 menu and dialog font (MS Sans Serif, 8 point), as a pixel-exact web font. Used by
classic mode's menu bar and dialog boxes (`css/classic-menu.css`).

Taken from the 98.css project (https://github.com/jdan/98.css, version 0.1.21, `dist/`), which
ships it under the MIT licence in `LICENSE` here (Copyright 2020 Jordan Scales). The glyphs are a
recreation of Microsoft's bitmap font; Microsoft's own font files are not included.
